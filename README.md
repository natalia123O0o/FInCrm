## 📌 ¿Qué es FinCRM?

**FinCRM** es una plataforma web SaaS multiempresa que reúne los procesos comerciales y administrativos de una PYME: clientes, oportunidades de negocio, actividades, cotizaciones, comunicaciones, deudas y pagos.

Su propósito es que la información no se quede únicamente almacenada: busca facilitar su registro, seguimiento y aprovechamiento para mejorar la relación con los clientes y apoyar las decisiones del negocio.

La **cobranza** es una parte importante de FinCRM, pero **no es su único enfoque**. También abarca el proceso comercial, la organización del equipo y herramientas de asistencia inteligente.

## 🎯 ¿Qué problema busca resolver?

Muchas empresas contratan CRM con numerosas funciones, pero sus equipos no siempre las utilizan, registran datos incompletos o no convierten la información en acciones. FinCRM busca simplificar el trabajo diario y conectar los datos de clientes con tareas, oportunidades, comunicaciones y resultados.

## 🚀 Funcionalidades de FinCRM

### 👥 Clientes

- Registrar, consultar y actualizar datos de clientes.
- Centralizar información de contacto e historial relacionado.
- Asociar clientes con oportunidades, actividades y deudas.

### 🎯 Oportunidades y cotizaciones

- Gestionar posibles negocios y sus etapas de seguimiento.
- Registrar responsables, valores estimados y avances comerciales.
- Organizar propuestas y cotizaciones para clientes.

### 📅 Empleados y actividades

- Administrar colaboradores de cada empresa.
- Crear y asignar llamadas, reuniones y tareas con prioridad y fecha límite.
- Consultar actividades pendientes, completadas y vencidas.
- Registrar resultados de seguimiento.

### 💰 Deudas, cartera y pagos

- Registrar deudas asociadas a clientes y consultar saldos.
- Registrar pagos o abonos y mantener el historial correspondiente.
- Dar seguimiento a obligaciones pendientes y gestiones de cobranza.

### ✉️ Mensajería y campañas

- Preparar mensajes personalizados de seguimiento comercial o cobranza.
- Organizar campañas, plantillas y destinatarios.
- Consultar información de campañas y resultados de comunicación.
- Considerar autorizaciones, horarios y frecuencia de contacto aplicables.

### 🛒 FinPOS

- Gestionar productos y precios.
- Registrar ventas y medios de pago.
- Llevar control de inventario, existencias e historial de ventas.

### 🎙️ FinVoice

- Facilitar consultas sobre productos mediante comandos de voz.
- Apoyar el registro de ventas por voz con confirmación previa.

### 🤖 Asistente inteligente y FinRadar

- Apoyar consultas y elaboración de mensajes con inteligencia artificial.
- Ofrecer sugerencias de seguimiento comercial y cobranza para revisión humana.
- Presentar indicadores de negocio y apoyar el análisis de información.
- Explorar tendencias y oportunidades de mejora mediante FinRadar.

## 🔐 Perfiles de usuario

| Perfil | Funciones principales |
| --- | --- |
| **SUPER_ADMIN** | Registra empresas, crea administradores y gestiona planes, funcionalidades y accesos. |
| **ADMIN** | Gestiona clientes, empleados, actividades, oportunidades, cartera y los módulos habilitados para su empresa. |
| **USER** | Consulta sus oportunidades y actividades asignadas, registra seguimientos y utiliza el asistente según sus permisos. |

FinCRM utiliza separación de información por empresa y controles de acceso según el rol del usuario.

## 🧰 Tecnologías utilizadas

| Área | Tecnologías |
| --- | --- |
| **Frontend** | React, Vite, JavaScript, HTML y CSS |
| **Backend** | Node.js, Express |
| **Base de datos** | MongoDB Atlas, Mongoose |
| **Autenticación y seguridad** | JWT, bcryptjs |
| **Validación** | Zod |
| **Inteligencia artificial** | Google Gemini API |
| **Pruebas y control de versiones** | Postman, Git y GitHub |

## 🇨🇴 Enfoque para empresas colombianas

FinCRM considera reglas de comunicación y cobranza relacionadas con la **Ley 2300 de 2023**, junto con la necesidad de respetar las autorizaciones de contacto y la protección de los datos personales.
